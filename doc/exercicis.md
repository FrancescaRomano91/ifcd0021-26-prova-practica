# Backend - Enrollment

## 1. Model

The backend contains three entities:
- Student
- Teacher
- Enrollment

Enrollment connects Student and Teacher through an intermediate entity.

## 2. API

The Enrollment API provides the following endpoints:

- GET /api/enrollments/getAll: retrieve all enrollments.
- POST /api/enrollments/create: create a new enrollment.
- DELETE /api/enrollments/delete: delete an enrollment.
